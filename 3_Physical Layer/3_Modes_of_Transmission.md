## Transmission Modes
Transmission Modes describe how data is exchanged between two devices over a communication channel. They specify whether information moves in a single direction or in both directions, and whether devices can transmit at the same time.

- Defines the pattern of communication
- Determines sender and receiver roles
- Influences speed and performance
- Used in networking and telecommunication systems

![Transmission modes](/Images/transmission%20mode.png)

### 1. Simplex mode
In simplex mode, data is transmitted in only one direction. The receiver cannot send data back to the sender.

- One-way communication.
- Sender only sends data.
- Receiver only receives data.

**Example:** Television broadcasting.

![simplex mode image](/Images/simplex%20mode.png)

### Advantages
- Simple and easy to implement.
- Low cost.
- Suitable when communication is required in only one direction.

### Disadvantages
- Communication is only one-way.
- The receiver cannot send a reply or feedback.

### 2. Half-Duplex Mode
In half-duplex mode, data can be transmitted in both directions, but only one direction at a time. The devices take turns sending and receiving data over the same channel.

- Two-way communication.
- Both devices can send and receive simultaneously.
- Provides continuous communication.

**Example:** Walkie-talkie.

![half-duplex mode image](/Images/half-duplex%20mode.png)

### Advantages:
- Allows two-way communication.
- Less expensive than full-duplex.
- Uses fewer communication resources.

### Disadvantages:
- Both devices cannot transmit simultaneously.
- Communication is slower than full-duplex.

## Full-Duplex Mode
In full-duplex mode, data can be transmitted in both directions simultaneously.

- Two-way communication.
- Both devices can send and receive simultaneously.
- Provides continuous communication.

**Example:** Telephone or mobile phone call.

![full-duplex mode image](/Images/full-duplex%20mode.png)

### Advantages:

- Fast communication.
- Allows simultaneous data transmission.
- More efficient for real-time communication.

### Disadvantages:

- More expensive.
- Requires more complex hardware.
- Needs greater communication resources.
