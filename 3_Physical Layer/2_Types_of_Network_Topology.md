## Peer-to-Peer (P2P) Topology
Peer-to-Peer (P2P) Topology is a network in which all computers (peers) are equal and can both share and access resources directly without a central server.

![P2P Topology Image](/Images/p2p%20topology.png)

### Advantages
- Low Cost: No dedicated server is required.
- Easy to Set Up: Simple to install and configure.
- Direct Resource Sharing: Files, printers, and other resources can be shared directly between computers.
- Suitable for Small Networks: Works well for homes and small offices.
### Disadvantages
- Less Secure: There is no central security or access control.
- Difficult to Manage: As the number of computers increases, management becomes harder.
- No Central Backup: Each computer is responsible for its own data.


## Bus Topology
In Bus Topology, one long cable acts as a single communication channel & all the devices are connected to this cable.

![Bus Topology Image](/Images/bus%20topology.jfif)

### Advantage 
- Low cost – Requires less cable, making it inexpensive.
- Easy to install – Simple to set up for small networks.
- Less cabling required – Uses a single backbone cable.

### Disadvantages
- Backbone failure – If the main cable fails, the entire network stops working.
- Difficult to troubleshoot – Finding faults can be challenging.
- Performance decreases – As more devices are connected, the network becomes slower.

## Mesh Topology
Mesh Topology is a type of network topology in which every device is directly connected to every other device through dedicated communication links.

![Mesh Topology Image](/Images/mesh%20topology.jfif)

### Advantages
- Highly Reliable: Failure of one connection does not affect the rest of the network.
- High Security: Data travels through dedicated links, making it more secure.
- Fast Communication: Data can take multiple paths, reducing delays.
- Easy Fault Detection: Faults can be identified and isolated easily.

### Disadvantages
- Expensive: Requires many cables and network ports.
- Complex Installation: Setting up and maintaining the network is difficult.
- More Cabling Required: Every device needs connections to all other devices.
- Not Suitable for Large Networks: Cost and complexity increase rapidly as devices are added.

## Star Topology
Star Topology is a type of network topology in which all computers and devices are connected to a central device, such as a hub or switch. All communication passes through the central device.

![Star Topology Image](/Images/star%20topology.jfif)

### Advantages
- Easy to Install and Manage: The network is simple to set up and maintain.
- Failure of One Device Does Not Affect Others: If one computer or cable fails, the rest of the network continues to work.
- Easy to Add or Remove Devices: New devices can be connected without affecting the network.
- Easy Troubleshooting: Faults can be detected and fixed quickly.
### Disadvantages
- Central Device Failure: If the hub or switch fails, the entire network stops working.
- More Cabling Required: Each device needs a separate cable to the hub or switch.
- Higher Installation Cost: More cables and a central device increase the cost.

## Ring Topology
Ring Topology is a type of network topology in which each computer or device is connected to two other devices, forming a closed circular path (ring). Data travels from one device to the next until it reaches the destination.

![Ring Topology Image](/Images/ring%20topology.jfif)

### Advantages
- No Data Collision: Data travels in one direction, reducing collisions.
- Equal Access: Every device gets an equal chance to transmit data.
- Good Performance: Performs well even with heavy network traffic.
- Orderly Data Transmission: Data moves in a fixed sequence.
### Disadvantages
- Single Failure Affects the Network: If one device or cable fails, the entire network may stop working.
- Difficult to Troubleshoot: Finding and fixing faults is difficult.
- Adding or Removing Devices is Difficult: The network must usually be interrupted to make changes.
- Maintenance is Costly: Repair and maintenance take more time.

## Tree Topology
Tree Topology is a type of network topology in which multiple star networks are connected to a main backbone cable, forming a hierarchical (tree-like) structure.

![Tree Topology Image](/Images/Tree-Topology.jpeg)

### Advantages
- Easy to Expand: New devices or branches can be added easily.
- Suitable for Large Networks: Ideal for schools, colleges, and offices.
- Easy to Manage: Different sections of the network can be managed separately.
- Fault Isolation: Problems in one branch usually do not affect other branches.
### Disadvantages
- Backbone Failure: If the main backbone cable fails, a large part of the network stops working.
- Expensive: Requires more cables and networking devices.
- Complex Installation: Designing and maintaining the network is more difficult than simpler topologies.
- High Maintenance: Needs regular monitoring and maintenance.

## Hybrid Topology
Hybrid Topology is a type of network topology that combines two or more different network topologies (such as Star, Bus, Ring, or Mesh) into a single network.

![Hybrid Topology Image](/Images/hybrid-topology.jpg)

### Advantages
- Highly Flexible: Different topologies can be combined according to network needs.
- Easy to Expand: New devices and network segments can be added easily.
- Reliable: Failure in one part of the network usually does not affect the entire network.
- Good Performance: Suitable for both small and large organizations.
### Disadvantages
- Expensive: Requires more cables, networking devices, and equipment.
- Complex Design: Installation and configuration are difficult.
- High Maintenance Cost: Managing and troubleshooting the network requires skilled professionals.
